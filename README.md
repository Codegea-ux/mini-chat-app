# 💬 Mini Chat App (Real-Time)

A modern real-time chat application built using WebSockets.

## 🚀 Features

* ⚡ Real-time messaging
* 🟢 Online user tracking
* 💬 Chat bubbles UI
* 🌙 Modern dark theme

## 🛠 Tech Stack

* Node.js
* Express
* Socket.IO
* HTML, CSS, JavaScript
